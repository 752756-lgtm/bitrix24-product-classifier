# Bitrix24 Product Classifier

Сервис загружает товарные категории из YML, читает товары сделки Битрикс24 и записывает в пользовательские поля сделки доминирующую категорию и подкатегорию. Доминирующая группа выбирается по сумме позиций (`цена × количество`).

## Быстрый запуск

1. Установите Python 3.11+.
2. Скопируйте `.env.example` в `.env` и заполните значения.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Проверка без записи в CRM: `python -m classifier --deal-id 123 --dry-run`.
5. Рабочий запуск: `python -m classifier --deal-id 123`.

Приложение не хранит секреты в репозитории. Для вебхука Битрикс24 рекомендуется создать входящий вебхук только с правами чтения товаров сделки и изменения сделок.

## Сопоставление товаров

По умолчанию предложение YML связывается с товарной строкой сделки по XML ID: `offer id` из YML должен совпадать со значением `PRODUCT_XML_ID` товарной строки. Если поле отсутствует, используется резервное сопоставление по нормализованному названию.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BITRIX_WEBHOOK_URL` | Базовый URL входящего вебхука, например `https://example.bitrix24.ru/rest/1/token/` |
| `YML_URL` | URL YML-фида |
| `CATEGORY_FIELD_TITLE` | Название поля категории; по умолчанию `Категория товаров (Сайт)` |
| `SUBCATEGORY_FIELD_TITLE` | Название поля подкатегории; по умолчанию `Подкатегория товаров (Сайт)` |
| `HTTP_TIMEOUT` | Таймаут HTTP, по умолчанию 30 секунд |

Программа автоматически определяет технические коды полей и ID значений списков по их названиям. Вебхук и URL YML хранятся только в `.env` на сервере.
